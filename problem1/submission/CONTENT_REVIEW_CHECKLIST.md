# MetaboQuest content review checklist

**Status: NOT clinician-reviewed.** Every row below has an empty sign-off column on purpose.

- Automated tests (unit, e2e, offline playable) check behaviour and wording rules. They do **not** establish medical accuracy.
- Content is source-checked against the public pages listed, but no clinician has signed it off. `reviewedBy` is `null` in `glp1-topic-bank-v9.json` and in `contentReview` (`frontend/src/data/topics.ts`).
- **A qualified clinician must review every row before any public use.** Only after that should `reviewedBy` be set and any review wording appear in the UI.
- Sources are mostly UK/US/WHO public-health pages and a few research papers, not Indian prescribing criteria. A reviewer should check Indian applicability (for example lower BMI/waist thresholds, local food examples).
- Several research and NIDDK/CDC pages block automated fetching; they were verified via mirrors/records noted in `.agents` task findings. Reviewer should re-open each link.
- `Claim` is an internal note for the reviewer and is never shown in the UI. For V8 and legacy rows the claim is paraphrased from the explanation.
